Guía Básica del Servidor Apache

Conceptos esenciales, directorios y comandos para principiantes

¿Qué es Apache?

El **Servidor HTTP Apache** es uno de los servidores web más populares y utilizados del mundo. Es un software libre y de código abierto que procesa peticiones HTTP y entrega contenido (páginas HTML, imágenes, archivos) a los navegadores de los usuarios.

Directorio Raíz (DocumentRoot)

Es la carpeta donde guardas los archivos de tu sitio web (como index.html).

  • En sistemas Linux (Ubuntu/Debian): /var/www/html/
  • En XAMPP (Linux): /opt/lampp/htdocs/
  • En XAMPP (Windows): Carpeta htdocs dentro del directorio de instalación

Estructura de Archivos en Linux

Los archivos de configuración principales de Apache se encuentran generalmente en:

  • /etc/apache2/apache2.conf o httpd.conf: Configuración global.
  • /etc/apache2/sites-available/: Definición de sitios virtuales (VirtualHost).
  • /etc/apache2/sites-enabled/: Sitios activos.

Comandos Básicos (Linux / systemctl)

Para controlar el servicio de Apache en la terminal, utiliza los siguientes comandos:

# Iniciar el servidor Apache
sudo systemctl start apache2

# Detener el servidor Apache
sudo systemctl stop apache2

# Reiniciar el servidor Apache
sudo systemctl restart apache2

# Comprobar el estado del servidor
sudo systemctl status apache2

Ejemplo de un archivo HTML básico

Para que Apache muestre una página al entrar a tu servidor, crea un archivo llamado index.html dentro de tu DocumentRoot con el siguiente contenido:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>Mi sitio en Apache</title>
</head>
<body>
    <h1>¡Hola Mundo desde Apache!</h1>
    <p>Este sitio está funcionando correctamente.</p>
</body>
</html>
